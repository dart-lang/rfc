# Dart RFCs

The RFC ("request for comments") process is intended to drive project wide
decisions. See [RFC-0001: RFC Process](rfcs/0001/0001_RFC_process.md) for the
details.

You can find all accepted RFCs in the `rfcs/` folder.

There are two mailing lists which can be used to monitor changes to the RFCs:

* rfcs@dartlang.org - a low traffic mailing list which receives curated
updates about RFCs
* rfcs-firehose@dartlang.org - a high traffic mailing list CCed on all changes
to RFC CLs.

# Dart Technical Council (DTC)

The DTC is responsible for facilitating the RFC process as well as making
final decision to approve or reject the RFC. Council can be reached via

* technical-council@dartlang.org for private communication with DTC
* technical-council-public@dartlang.org for public communication with DTC
